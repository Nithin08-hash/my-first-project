# KNOVIXA

A mobile-friendly student learning website and installable Progressive Web App (PWA) starter.

## Features in this starter
- Responsive home page and learning hub
- Search learning tools
- Demo quiz, study planner, note editor and PYQ organiser
- Install prompt support where the browser supports it
- Basic service-worker caching

## Publish the website
1. Open the repository Settings on GitHub.
2. Choose **Pages** in the left menu.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait for the Pages deployment and open the URL shown in Settings → Pages. It will usually look like `https://Nithin08-hash.github.io/my-first-project/`.

## Android app
This starter is an installable PWA on supported Android browsers (open the published HTTPS website in Chrome and use **Install app** or **Add to Home screen**). A Play Store APK/AAB requires an additional Android packaging and testing/signing process.

## Important
This is a starter/demo, not the complete production platform. Student accounts, synced progress, verified question-paper content, friend invites, leaderboards and an AI tutor require secure backend services and content. Never put API keys or private student data in frontend code.
